## 1. そもそも夫婦とは

### 1-1. 結婚に求めるものが「生活」から「自分らしさ」に変わった ○
- 社会心理学者イーライ・フィンケルは、アメリカの結婚を3つの時代に分けて説明している（Finkel et al., 2014／著書『The All-or-Nothing Marriage』2017）
  1. **制度の結婚**：食べていく・家を守るための結婚
  2. **愛情の結婚**：愛し合う二人の結婚
  3. **自己表現の結婚**（1965年〜）：「この人といると自分らしくいられる・成長できる」ことまで求める結婚
- 求めるものが増えたぶん、**期待に届かない夫婦が増えて満足度は平均的に下がった**。一方で、期待に届いた夫婦は昔のどの時代の夫婦よりも満たされている。だから「オール・オア・ナッシング」と呼ばれる
- **セミナーでの言い方**：「いまの結婚は、昔より“求めるもの”がずっと多い。うまくいかないと感じるのは、あなたがダメだからじゃなくて、結婚に求めるハードルが時代とともに上がったから」

### 1-2. 日本でも結婚は「恋愛でするもの」になった ○
- 出生動向基本調査（第16回・2021年）では、恋愛結婚が約75%（74.6%）、見合い結婚が約10%（9.9%）。戦前とは割合が完全に逆転している
- ＝「好きだから結婚した」が前提になったぶん、「好きじゃなくなった＝失敗」と感じやすくなっている

### 1-3. 心理学的には、パートナーは大人にとっての「安全基地」 ○
- 愛着理論：子どもが親を「安全基地」にするように、大人は恋人や配偶者を安全基地にする（Hazan & Shaver, 1987 の成人の愛着研究）
- 脳でも確認されている（→ 5-2 の手つなぎ実験）：信頼できるパートナーがそばにいると、脳が脅威に反応しにくくなる
- **セミナーでの言い方**：「夫婦は、生活のチームでもあり、お互いの“安全基地”でもある。だからこそ、そこが揺らぐと、こんなにしんどい」

## 2. 数字で見る夫婦関係

### 2-1. 夫婦関係に満足している人は、だいたい「3人に2人」 ○
| 調査 | 対象 | 満足 |
|---|---|---|
| リクルート ブライダル総研「夫婦関係調査2021」 | 20〜60代の既婚者 | **67.2%**（妻66.7%・夫67.7%） |
| ハルメク「シニアの夫婦関係調査2023」 | 50〜70代 | **68.3%**（夫72.0%・妻64.7%） |
| ソニー生命「20代・30代共働き夫婦の生活意識調査2025」 | 20〜30代の共働き夫婦 | 「良好」58.8%／「どちらともいえない」36.1%／「険悪」5.1% |

- 裏返すと、**およそ3人に1人は満足していない**
- 「どちらともいえない」の層が厚い（ソニー生命調査では36%）。セミナーで一番刺さりやすいのは、「不満ってほどじゃないけど、このままでいいのかな」と感じているこの層かもしれない
- リクルート調査では、コロナ禍で共働き世帯の満足度は上がり、専業主婦・兼業主婦世帯の妻は下がる傾向だった。「1時間以上の会話」と「感謝の言葉」が満足度と関係していた

### 2-2. 多くの調査で「妻のほうが満足度が低い」 ○
- ハルメク調査では男女差が7.3ポイントで、項目によっては最大22ポイント差
- 日本の学術研究でも、どの年代でも妻の満足度が夫より低いという報告がある（J-STAGE掲載論文：夫81.7〜96%、妻69.6〜83.2%）
- 家事分担への満足度：男性は約86%が満足、女性は約54%（一条工務店 2024）
- 妻の満足度を左右するのは「経済的な信頼」より**「精神的な信頼」**で、説明力は約3倍（RIETIの研究紹介）
- 会話時間は、**妻の満足度とは常に関係するが、夫の満足度とは関係しない場合がある**（北海道大学の学位論文）
- ※例外もある：20〜30代共働きのソニー生命調査では、女性（66.6%）のほうが男性（51.0%）より「良好」と答えた

### 2-3. 子どもが生まれると満足度は下がりやすい（とくに妻） ◎〜△
- **メタ分析（49研究, Frontiers in Psychology 2022）◎**：妊娠中から産後12ヶ月にかけて中程度に低下し、12〜24ヶ月でさらに少し下がる。夫婦どちらにも起きる。片方が大きく下がると、もう片方も下がりやすい
- **Twenge et al. (2003) のメタ分析 ○**：子どもがいる夫婦は満足度がやや低い。乳幼児の親、とくに母親で差が大きい（効果の大きさは「小」）
- **ベネッセ「妊娠出産子育て基本調査」△**：「配偶者といると本当に愛していると実感する」と答えた割合
  | 時期 | 妻 | 夫 |
  |---|---|---|
  | 妊娠期 | 約7割（報告書では71.3%、記事では74.3%） | 約7割 |
  | 0歳 | 45.5% | 63.9% |
  | 1歳 | 36.8% | 54.2% |
  | 2歳 | **34.0%** | 51.7% |
  - いわゆる「産後クライシス」の根拠としてよく使われる数字。ただし原典の報告書PDFは確認できていない。妊娠期の数字も資料によって71.3%と74.3%で食い違っているので、**使う前に原典で確認する**
  - 原典では、妻側の0歳までの低下幅（31.9ポイント）が全項目で最大とされている

### 2-4. 家事・育児は、いまも妻に8割 ◎
- 第7回全国家庭動向調査（2022年）
  - 家事時間：妻は平日247分、夫は平日47分（休日は妻276分・夫81分）
  - 家事の分担：**妻が8割超**（低下傾向ではある）
  - 育児の分担：妻が7割超
- 「夫は外で働き、妻は家庭」への賛成は29.5%で過去最低。**「意識」は変わったのに「実態」は追いついていない**。このギャップそのものが不満の種になる

### 2-5. 離婚の数字 ◎
- 2024年の離婚件数は**18万5,895組**（前年より2,081組増、2年連続の増加）。ピークの2002年（約29万組）の約64%
- 同居20年以上の「熟年離婚」は全体の**約22%**
- 「3組に1組が離婚する」は、**同じ年の婚姻件数と離婚件数を比べただけの数字**で、実際に離婚する夫婦の割合ではない。セミナーでは使わない
- 家庭裁判所に持ち込まれた離婚の申立て動機は、夫も妻も**「性格が合わない」が1位**（令和6年：夫約60%、妻約38%）。妻側の2位は「生活費を渡さない」（司法統計年報 家事編）
  - ただし家庭裁判所を通る離婚は全体の約1割。話し合いで決まる協議離婚は含まれない

### 2-6. 夫婦仲は、心と体の健康に直結する ◎
- **メンタル**：93研究のメタ分析で、夫婦関係の質と本人の幸福感ははっきり関係している（Proulx et al., 2007）。関係は男性より女性のほうが強い傾向
- **体**：126研究・7万2千人以上のメタ分析で、夫婦関係の質が高い人ほど健康で、死亡リスクも低い（Robles et al., 2014）
- **ケンカと免疫 ○**：敵意の強いケンカをする夫婦は、傷の治りが穏やかな夫婦の**約60%の速さ**しかなく、炎症物質（IL-6）は約1.5倍だった（Kiecolt-Glaser et al., 2005／42組）
- **セミナーでの言い方**：「夫婦仲は気分の問題じゃなくて、健康の問題でもある。だから“我慢すればいい”で済ませなくていい」

## 3. 夫婦仲はなぜ悪くなるのか（心理学）

### 3-1. 誰かが悪いのではなく、「よくある流れ」がある
| 原因 | 中身 | 根拠 |
|---|---|---|
| ① 期待が高くなった | 結婚に「自分らしさ・成長」まで求めるようになり、届かない夫婦が増えた | Finkel ○ |
| ② 慣れ（快楽順応） | 結婚直後の幸福感は数年で元の水準に戻りやすい。「好き」が当たり前になる | Lucas et al., 2003 ○ |
| ③ ライフイベントとストレス | 出産・育児・仕事・介護など外のストレスが夫婦の中に持ち込まれる（ストレスの持ち込み） | Neff & Karney ○／産後の満足度低下 ◎ |
| ④ 悪いことのほうが強く残る | 嫌な出来事は良い出来事より記憶に残りやすく、影響も大きい（ネガティビティ・バイアス） | Baumeister et al., 2001 ◎ |
| ⑤ 解釈のクセ | 相手の嫌な行動を「性格だから」「いつもそう」と解釈すると、満足度が下がる。その解釈が、のちの満足度を予測する | Bradbury & Fincham ○ |
| ⑥ 追う・逃げるの往復 | 片方が責める・求める → もう片方が黙る・離れる → さらに責める（要求−引きこもりパターン）。不満のある夫婦ほど強く出る | Schrodt et al., 2014（74研究・1万4千人のメタ分析）◎ |
| ⑦ 解決しない問題がある | 夫婦の問題の**約69%は「ずっと続く問題」**（性格や価値観の違い）。解決ではなく「付き合い方」が大事 | Gottman ○（臨床観察ベース） |

### 3-2. ⑥「追う・逃げる」の補足
- 「妻が求めて、夫が引く」形のほうが多い。ただし、逆の形（夫が求めて妻が引く）も同じくらい関係を傷つける ＝ **男女の問題ではなく「パターン」の問題**
- 講座の第6回（二人のあいだで起きている循環を見る）がそのまま対応する

### 3-3. ⑦「69%」の補足
- 解決できる問題は31%。残りは「なくす」ものではなく「扱い方を覚える」もの
- うまくいっている夫婦は、問題があっても「相手を受け入れつつ、改善もしたい」という両方を伝えられている
- 講座の第2回（変えられること／変えられないことを分ける）と相性がいい

## 4. 行き違いはなぜ起きるのか

### 4-1. 「夫婦なら分かり合えている」は錯覚 ○
- **近さ−伝達のバイアス**（Savitsky, Keysar, Epley, 2011）：夫婦に、あいまいな言い回しの意味を当て合ってもらう実験（24組）
  - 夫婦は「相手は分かってくれるはず」と見積もりすぎていた
  - **実際の正答率は、赤の他人とのペアと変わらなかった**
  - 親しいほど「言わなくても分かるはず」と思い込み、相手の立場で考えるのを省いてしまう
- **セミナーでの言い方**：「夫婦が分かり合えていないのは、愛がないからじゃない。“近いから伝わってるはず”と脳が手を抜くから」

### 4-2. 「当たり前」が違う
- 夫婦はそれぞれ、育った家から「夫婦とは」「親とは」「家事とは」という前提を持ち込んでいる。言葉になっていないので、ぶつかるまで気づかない（講座 第8回）
- 意識と実態のギャップ（2-4）：「家事は二人で」が当たり前の妻と、「手伝っている」つもりの夫で、同じ状況でも見え方が違う

### 4-3. 相手の行動は「性格」のせいにしやすい
- 自分の行動は「状況のせい」、相手の行動は「性格のせい」と考えやすい（基本的な帰属の誤り）
- 不満のある夫婦ほど、相手の嫌な行動を「変わらない性格」のせいにする（3-1 ⑤）

### 4-4. 疲れていると、脳は相手の気持ちを読めなくなる ○
- **睡眠**：寝不足の翌日はパートナーとのケンカが増え、仲直りもしにくい。もともとよく眠れている人でも、一晩眠れないだけで起きる（Gordon & Chen, 2013／UCバークレー）
- **ストレス**：強いストレスがかかると、冷静に考える脳（前頭前野）の働きが落ち、反射的に反応する脳（扁桃体など）が優位になる（Arnsten, 2009 のレビュー）。カッとなったときに「正論」が通じないのはこのため
- 子育て中は睡眠不足とストレスが重なりやすい時期 ＝ 行き違いが起きて当然の条件がそろっている

## 5. 脳科学の視点

### 5-1. 長く続く夫婦でも「恋の脳」は働きうる ○
- 結婚して平均21年の夫婦17人の脳を調べた研究（Acevedo et al., 2012）。パートナーの写真を見ると、恋をしたばかりの人と同じ**ドーパミン系の報酬回路（腹側被蓋野）**が反応した
- **セミナーでの言い方**：「“長く一緒にいたら恋愛感情はなくなるもの”とは限らない。脳の研究では、20年たっても恋をしたばかりの人と同じ反応をする夫婦がいる」
- ※小サンプル・選ばれた夫婦なので「誰でもそうなる」とは言わない

### 5-2. 夫と手をつなぐと、脳の「恐怖反応」が下がる ○
- 既婚女性16人に、軽い電気ショックの予告を出して脳を測った実験（Coan et al., 2006）
  - 夫の手を握る：脅威への反応が大きく下がった
  - 知らない人の手：少し下がった
  - 誰の手も握らない：下がらない
  - **夫婦関係の満足度が高い人ほど、下がり方が大きかった**
- 「パートナーは脳にとっての安全基地」を示す代表的な研究（1-3 とつながる）

### 5-3. オキシトシンは、ケンカ中の会話をやわらげる ○
- 47組の夫婦にオキシトシンか偽薬を鼻から吸入してもらい、ケンカの話し合いをしてもらった実験（Ditzen et al., 2009）。オキシトシン群は、前向きなやりとりが増え、ストレスホルモン（コルチゾール）が下がった
- ※効果は「ぎりぎり有意」レベル。「スキンシップでオキシトシンが出るから仲良くなる」とまで言うと言い過ぎ。紹介は「触れ合いや安心感には、体の仕組みとしての裏づけもある」程度にとどめる

### 5-4. 母親の脳は、出産で「赤ちゃん仕様」に変わる ○
- 初産の女性25人の脳を妊娠前と出産後に比べた研究（Hoekzema et al., 2017, Nature Neuroscience）。他人の気持ちを読む領域の灰白質が変化し、約2年後も続いていた
- 研究者はこれを「劣化」ではなく、**赤ちゃんの気持ちを読むための最適化**と解釈している
- **セミナーでの言い方（注意して）**：「産後に夫への気持ちが変わるのは、あなたが冷たくなったからじゃない。脳と体が、全力で赤ちゃんを守るモードに切り替わっているから」
  - ※「脳の変化が原因で夫への愛情が下がる」と直接示した研究ではない。因果関係を言い切らないこと

### 5-5. ケンカは脳と体にとって「脅威」になる
- 敵意のあるケンカは免疫・炎症に影響する（2-6 Kiecolt-Glaser）
- ストレス下では前頭前野が働きにくくなる（4-4 Arnsten）
- 「ケンカ中に冷静になれないのは、性格じゃなく脳の仕組み」 → 一度離れてクールダウンする意味が説明できる

## 6. セミナー用：メッセージの骨格案

リサーチから組み立てられる流れの一例。

1. **共感（数字）**：満足しているのは3人に2人。裏を返せば3人に1人は満足していない。とくに妻、とくに産後に下がりやすい（2-1〜2-3）
2. **あなたのせいじゃない（心理学）**：結婚への期待は上がり、慣れは誰にでも起き、子育て期はストレスと寝不足がそろう。追う・逃げるのパターンは「性格」ではなく「流れ」（1-1, 3, 4-4）
3. **行き違いの正体（心理学＋脳科学）**：夫婦は「伝わっているはず」と錯覚しやすい。疲れた脳は相手の気持ちを読めない。当たり前は育った家で違う（4）
4. **希望（脳科学）**：パートナーは脳にとっての安全基地になれる。20年たっても恋の脳が働く夫婦もいる（5-1, 5-2）
5. **だから「夫を変える」ではなく「自分が選べるようになる」**：69%の問題は解決ではなく付き合い方。変えられるのは自分の一手と解釈（3-3 → 講座の12回へ）

### 講座の12回との対応
| リサーチの論点 | 講座の回 |
|---|---|
| ネガティビティ・バイアス／悪いことが全体に見える | 第1回 見取り図、第3回 気分メモ |
| 69%は解決しない問題 | 第2回 変えられる／変えられない |
| 愛着・安全基地 | 第4回 愛着の傾向 |
| 寝不足・ストレスで怒りが出る | 第5回 イライラの下の気持ち |
| 追う・逃げる（要求−引きこもり） | 第6回 循環を見る |
| 帰属のクセ | 第7回 夫の行動の理由 |
| 当たり前のズレ／意識と実態のギャップ | 第8回 当たり前のズレ |
| 近さ−伝達のバイアス | 第9回 愛情の伝わり方、第11回 お試し会話 |
| 解釈のクセ（解釈は選べる） | 第10回 見方を変える |
| 期待の上昇／自分で選ぶ | 第12回 選ぶ・動く |

## 7. 使わない・言い方に注意する数字

| 数字 | 判定 | 理由 |
|---|---|---|
| 「3組に1組が離婚」 | ✕ 使わない | 同じ年の婚姻数と離婚数を比べただけ。実際の離婚率ではない |
| ゴットマン「離婚を94%の精度で予測」 | △ 言い切らない | 一次論文では93.6%、73組の小サンプルで、後付け分析だという批判がある |
| 「シャットダウンする側の85%は男性」 | ✕ 使わない | 出典を確認できない |
| 「幸せな夫婦はbidへの応答が20倍」 | ✕ 使わない | 誤り。一次データは「85%以上 vs 33%程度」（約2.6倍） |
| ラブランゲージ5分類 | △ | 学術的には支持されていない（講座でもそう説明している） |
| ベネッセ「愛情曲線」74.3%→34.0% | △ 原典を確認 | 妊娠期の数字が資料によって71.3%と74.3%で食い違う |
| 「オキシトシンで仲良くなる」 | △ 言い過ぎ注意 | 実験の効果はぎりぎり有意。単純化しない |
| 「産後の脳の変化で夫への愛情が下がる」 | ✕ 因果を言わない | 脳の変化と夫への愛情の関係を直接示した研究ではない |
