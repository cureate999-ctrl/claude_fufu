メソッド3ステップとゴールの案

作成日：2026年10月17日
前提：対象は子育て中の20〜30代の女性。Zoomで録画したものを配信。講座の3つのまとまり（自分を知る／夫を知る／選ぶ・動く）を使い、キャッチーな名前をつける。セミナーのゴールは講座の申し込み。ミニワークを入れる。


セミナーで約束するゴール（「今より少し」良くなった状態）の案

ゴールは、受講者が「夫が変わらなくても、自分から始められること」にしておくのがポイントです。講座のコンセプトである「夫を変える講座ではない」とも合いますし、録画を見た当日から試せます。

ゴール案A　会話が、今より少し増える
例：1日5分、子どもの話ではない「二人の会話」がある。
根拠：リクルートの夫婦関係調査（2021年）では「1時間以上の会話」と「感謝の言葉」が満足度と関係していました。日本の研究では、会話時間は妻の満足度と常に関係していました。ゴットマンの研究では、うまくいっている夫婦は相手からの小さな呼びかけ（「ねえ、見て」など）の約85%以上に応えていて、うまくいかなかった夫婦は約33%にとどまっていました。

ゴール案B　ケンカしても、仲直りできる
例：ケンカのあと、どちらかが「さっきは言い方がきつかったね」と言える。謝れる、謝ってもらえる。
根拠：夫婦の問題の約69%は解決しない「ずっと続く問題」です。うまくいく夫婦はケンカをしないのではなく、ケンカのあとに関係を修復できる夫婦です。子どもにとっても、ケンカのあとに仲直りする姿を見ることが安心につながります（カミングスの研究）。講師ご自身のストーリーとも、いちばん強くつながるゴールです。

ゴール案C　触れ合いが、今より少し戻る
例：「いってらっしゃい」のときに背中に手を置く、ソファで隣に座る、など。
根拠：夫と手をつなぐと脳の恐怖反応が下がり、満足度の高い夫婦ほど下がり方が大きかった（コーンの研究、2006年）。夫婦で10分手をつなぎ、20秒ハグしたあとは、女性の血圧やストレスの反応が下がっていたという研究もあります（グリューエンらの研究、2005年）。

おすすめ：セミナーの約束はひとつにまとめ、3つの変化はその中身として見せるとわかりやすくなります。
例：「ケンカしても、ちゃんと戻ってこられる夫婦になる。そのために、会話・仲直り・触れ合いを、今より少しだけ増やす。」
ゴールを3つ並べるだけだと「全部やらなきゃ」と感じて重くなります。「3つのうち、いまの自分にいちばん近いものを1つ選ぶ」形にすると、ステップ3のミニワークとそのまま連動できます。


メソッド3ステップの名前の案

講座の3つのまとまりにそのまま対応させています。

案1（おすすめ）　きづく → ほどく → つなぐ
ステップ1「きづく」：自分の本当の気持ちに気づく（講座の「自分を知る」）
ステップ2「ほどく」：二人のあいだのもつれをほどく（講座の「夫を知る」）
ステップ3「つなぐ」：会話・仲直り・触れ合いで、もう一度つながる（講座の「選ぶ・動く」）
3つとも平仮名3文字で、リズムよく覚えやすい。「もつれをほどく」「もう一度つなぐ」は、20〜30代の女性向けのやわらかい言葉としても使いやすいと思います。

案2　地図をつくる → 天気を読む → 一歩をふみだす
自分の心の地図をつくる／二人のあいだの天気（パターン）を読む／小さな一歩をふみだす。比喩でイメージしやすく、ワークシートやスライドのデザインにも展開しやすい案です。

案3　わたしの取扱説明書 → ふたりのクセ発見 → 小さな一手
「取扱説明書」は自己理解系のコンテンツで伝わりやすい言葉です。ステップ2を「ふたりのクセ」とすることで、「夫の性格」ではなく「二人のパターン」を見るという考え方が名前に表れます。

案4　セルフマップ → ループリセット → スモールトライ
カタカナでまとめた案。メソッド名としての「型」っぽさは出ますが、やや硬く、寄り添いのトーンとは少し距離があります。


各ステップの中身と、セミナー中のミニワーク（案1の名前で記載）

ステップ1　きづく　――イライラの下にある「本当の願い」に気づく
話す内容：「夫にイライラする」はかたまりで、そのままでは手がつけられない。分けると場所が見える。怒りの下には「本当はこうしてほしかった」という願いがあることが多い。ただし、その前に「これは寝不足や疲れのせいではないか」を確かめる。自分の気持ちがわからないままでは、相手に伝えることも、相手の気持ちを想像することもできない。
根拠：感情に細かく名前をつけられる人ほど対処がうまくいく（感情粒度）。寝不足の翌日はケンカが増え、相手の気持ちを読む力が落ちる。
ミニワーク（約3分・画面を止めてもらう）：最近いちばんイラッとした場面をひとつ思い出して、紙に3行書く。「何があったか」「どう感じたか」「本当はどうしてほしかったか」。最後に「それは、寝不足や疲れのせいもある？」に○か×をつける。
講師のストーリーとのつながり：「自分の気持ちを押し殺してきたら、相手の気持ちもわからなくなった」という体験は、このステップの必要性をそのまま語れます。

ステップ2　ほどく　――「夫が悪い」から「二人のクセ」に見方を変える
話す内容：片方が責めると、もう片方が黙る。黙られるとさらに責めたくなる。これは性格ではなく、二人で回しているパターン。だから、片方の一手が変われば、往復も変わる。また、人は相手の嫌な行動を「そういう性格だから」と考えやすいが、仕事や寝不足、実家との関係など、状況の側にも理由があることが多い。夫婦は「言わなくても伝わっている」と思いやすいが、実験では赤の他人とのペアと同じくらいしか伝わっていなかった。
根拠：要求−引きこもりパターンのメタ分析（74研究）。解釈のクセと満足度の研究。近さ−伝達のバイアスの実験。
ミニワーク（約3分）：ステップ1で書いた場面を使って、空欄を埋める。「この場面で、私が（　　）すると、夫は（　　）になりやすい」。そのうえで、夫の行動の理由を「性格」以外で1つ考えてみる（例：仕事で疲れていた、どう返せばいいかわからなかった）。

ステップ3　つなぐ　――会話・仲直り・触れ合いのどれか1つを、小さく試す
話す内容：大きく変えようとしない。変えるのは一度にひとつだけ。うまくいかなくても失敗ではなく、情報が手に入っただけ。「やる気」より「段取り」。「もし○○になったら、△△する」と先に決めておくと、実行しやすくなる。
根拠：実行意図（if-thenプランニング）の研究。会話・仲直り・触れ合いの研究（ゴール案A〜Cの根拠）。
ミニワーク（約3分）：3つのゴールから、いまの自分にいちばん近いものを1つ選び、「もし○○になったら、△△する」を1行で書く。
会話の例：「もし子どもが寝たら、“今日どうだった？”と1回聞く」
仲直りの例：「もしケンカしたら、次の日の朝までに“昨日は言い方きつかったね”と言う」
触れ合いの例：「もし夫が出かけるときは、“いってらっしゃい”と言いながら背中に手を置く」
セミナーの締めにつなげる：「今日はこの1行だけで大丈夫です。でも、1行だけで続けるのは難しい。なぜこじれるのかを一つずつほどきながら、12か月かけて“戻ってこられる夫婦”をつくっていくのが、この講座です。」


講師のストーリーの位置づけ（自己紹介パート）

いただいたストーリーは、セミナー全体のテーマとかなり強くつながっています。とくに次の3点です。

1つ目は、リサーチ3で調べた「両親の対立が子どもに影響する理由」を、実体験として語れることです。顔色をうかがうようになった（家が安全かどうかを常に確かめていた）、大人を信用できなくなった、自分の気持ちを制限するようになった、子どもを持ちたいと思えなかった。研究で説明されていることを、当事者の言葉で伝えられます。研究の話だけだと「ふーん」で終わるところが、「これは本当に子どもに起きることなんだ」という実感に変わります。

2つ目は、「型がない」というテーマとつながることです。ご両親の世代は、ちょうど「夫は外、妻は家」から共働きへと夫婦のかたちが変わっていく時代を生きていました。両親を責めるのではなく、「両親も、うまくいく夫婦の型を知らなかったんだと思う」と語ると、聞いている人が自分の親や自分自身を責めずに済み、受け止めやすくなります。

3つ目は、「夫を変える講座ではない」というコンセプトとつながることです。「コントロールする親を見てきたから、自分も子どもや他人をコントロールしてしまいそうで怖かった」という話は、「相手を変えようとするのではなく、自分が選べるようになる」という講座の考え方に、自然につなげられます。

語るときの注意点として、受講者は「いま子育て中の母親」です。「親の不仲は子どもにこんな影響がある」という話は、聞き方によっては「自分の子どもにもう悪い影響を与えてしまった」という罪悪感につながります。ストーリーのあとに「だからといって、ケンカをしてはいけないわけではありません。大事なのは、ケンカのあとに仲直りできることです」という希望の一言を必ず添えると、罪悪感ではなく「だから変わりたい」という前向きな気持ちにつながりやすくなります。


改訂（v2）　決まったことと、ステップ名の追加案

決まったこと
セミナーのゴールは「夫婦仲が、今より少し良くなる」。夫が変わらなくても自分から始められることにする。中心に置く変化は「会話が、今より少し増える」。
講師は独身で子育てはしていない。サポートスタッフは3人で全員既婚（子どもあり／子どもなし／子どもなしで国際結婚）。

ステップ2「ほどく」の言いかえ案（案1のリズムを残す場合）
「きづく → よみとく → つなぐ」：夫の言動や、二人の会話がかみ合わない理由を「読みとく」。謎解きのように前向きに聞こえる。
「きづく → みなおす → つなぐ」：「夫はこういう人」という見方を「見直す」。意味がいちばんストレートに伝わる。
「きづく → わかる → つなぐ」：いちばん平易。ただし「夫をわかる」は重く聞こえる可能性がある。

会話をゴールにした新しい案
「ことば」シリーズ：自分のことばを見つける → 夫のことばを翻訳する → ふたりのことばを増やす
「きく・きく・はなす」シリーズ：自分の心の声をきく → 夫の声をきく → ふたりで話す

各ステップを「会話」のゴールに合わせた中身
ステップ1：自分が本当は何を話したいのか、何をわかってほしいのかを言葉にする。言葉にならないままでは、会話はケンカか沈黙になりやすい。
ステップ2：会話がかみ合わない理由を知る。追う・逃げるの往復、「言わなくても伝わる」という思い込み、求めているもののズレ（手を動かしてほしい妻と、話を聞けばいいと思っている夫）。
ステップ3：自分から始められる小さな会話の一手を、1つだけ決める。「話しかける」だけでなく、「夫からの小さな呼びかけに一言返す」も自分から始められる一手になる（うまくいっている夫婦は相手の呼びかけの約85%以上に応えていた）。
